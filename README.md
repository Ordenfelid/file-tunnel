# Result to Asset（结果落附件）

给思源 Agent 加一个 `exec` 工具：以二进制安全的方式调用 MCP 工具和内核工具。

## 它解决什么问题

有些 MCP 工具会返回图片、音频、视频或文件。这类内容以 base64 编码回传时，思源会把整段编码塞进对话上下文——一张图几十 KB 的文本，几轮就把对话撑爆，模型既看不清也用不上。

装上本插件后，Agent 会多出一个 `exec` 工具。凡是可能返回二进制结果的调用，Agent 改走它：

- 文本结果原样返回，和直接调用没有区别；
- 二进制结果自动保存到工作空间 `assets/mcp/` 目录，对话里只出现一行路径和文件信息（类型、大小），不再出现 base64；
- 保存下来的路径就是标准附件路径，可以直接插进文档、参与同步和备份。

反过来，需要**给工具传文件**时（比如把笔记里的图片发给图像处理服务），`exec` 支持在参数里指定附件路径，文件内容会以 base64 注入到工具参数中发出——模型全程只碰路径，不搬运编码。

## 怎么用

无需配置。在「设置 → AI → MCP」里配好的服务器，`exec` 会自动识别：

- 对 Agent 说「用 xx 工具生成一张图并存到笔记里」，Agent 自然会选用 `exec`；
- 插件不会改动你已有的任何 MCP 配置和原生工具——`exec` 只是一条额外的包装通道，原生工具照常可用。

## 边界

- 使用 OAuth 授权的 MCP 服务器无法经 `exec` 代调（凭据由思源内核管理）。这类调用会立刻报错并告诉 Agent 改用哪个原生工具，不会静默失败。
- `stdio` 类型的服务器仅在桌面版可用。桌面版访问外部 HTTP 服务器走直连通道，不受系统代理影响；浏览器和移动端受浏览器网络策略限制，个别服务器可能连不上。
- 落盘文件进入工作空间 `assets/mcp/`，会随同步与快照管理。

## 安装

从思源集市安装，或下载 Release 中的 `package.zip`，在「设置 → 集市 → 已下载 → 本地插件」导入。
